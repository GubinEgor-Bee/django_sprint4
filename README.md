# Blogicum

Blogicum — это веб-приложение, разработанное на Django, представляющее собой социальную сеть для публикации личных дневников и статей.

Пользователи могут создавать собственные публикации, объединять их по категориям, указывать местоположение, просматривать записи других авторов и оставлять комментарии.

# Возможности

* регистрация и авторизация пользователей;
* создание, редактирование и удаление публикаций;
* просмотр публикаций по категориям;
* страницы пользователей;
* добавление местоположения к публикациям;
* система комментариев;
* административная панель Django для управления контентом;
* модерация пользователей и публикаций.
